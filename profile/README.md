## About

The **Liberu Control Panel** is an open-source, Dockerised web hosting control panel built with a modern tech stack. It provides a powerful and user-friendly interface for managing websites, domains, databases, email accounts, and more — all from a single dashboard.

The project is built using the following technologies:

- **PHP 8.5** — top performance and security for modern web applications.
- **Laravel 12** — a powerful PHP framework for building scalable web applications.
- **Filament 5** — a beautiful admin panel and form builder for rapid development.
- **Livewire 4** — dynamic, real-time interfaces built entirely in PHP/Laravel.
- **Docker & Docker Compose** — containerisation for simple, reproducible deployment.
- **MySQL** — reliable relational database management.
- **Nginx** — high-performance web server and reverse proxy.
- **Postfix** — robust mail transfer agent for email hosting.
- **Dovecot** — secure IMAP and POP3 email server.
- **Bind9** — industry-standard DNS server for domain management.
- **JavaScript (ECMA2020)** — modern front-end scripting.

---

## Features

- **User Management** — secure authentication and role-based authorisation.
- **Website Management** — create, modify, and manage multiple websites easily.
- **Domain Management** — add and manage domain names and DNS records.
- **Database Management** — create, manage, and back up MySQL databases.
- **SSL Certificates** — generate and manage SSL certificates for secure connections.
- **File Management** — upload, edit, and organise files with an intuitive file manager.
- **Monitoring & Logs** — track usage statistics and access logs.
- **Backup & Restore** — automated backups and easy restoration processes.
- **Email Management** — set up and manage email accounts and forwarding.
- **Responsive Design** — access the control panel from any device.
- **Docker Integration** — simplified deployment and container management.
- **Extensible Architecture** — modular design for adding new features and integrations.
